# Cursor Agent Browser 技术验证提示词

在 Cursor 3.15.x Agent Window 中，从输入框选择 `/use-browser`，再提交以下内容。不要把 `/use-browser` 当成普通文本手工拼接；应选择 Cursor 提供的命令项。

请使用 Cursor 原生 Browser 对我提供的正流程测试用例进行浏览器自动化技术验证。

输入：

- 测试环境 URL：`<填写 URL>`
- 运行配置：`<填写配置文件路径，或直接粘贴内容>`
- 测试用例：`<填写用例文件路径，或直接粘贴 3～10 条用例>`

执行要求：

1. 只操作和观察浏览器，不读取或修改项目代码，不调用内部 API，不访问数据库，不修复发现的问题。
2. 只使用 Cursor 原生 Browser；如果出现 `cursor-ide-browser` 未找到等错误，原样记录并将本次运行标记为 `blocked`，不要自行安装其他浏览器框架。
3. 测试用例只读，全部按顺序执行，并假设彼此独立。
4. 业务步骤与预期结果必须严格遵守；只允许适应关闭提示、滚动、等待、切换标签页等界面操作。
5. 每一步都检查对应预期，不能因为点击成功就判定用例通过。
6. 普通账号密码由测试配置提供。短信账号标记为“浏览器自动填入”时，点击获取验证码后等待页面自动填写。
7. 每条用例只能标记为：`passed（已通过）`、`failed（不通过）`、`blocked（测试受阻）`、`inconclusive（无法判断）`。
8. 成功时截取最终页面；失败、受阻或无法判断时立即截图，并记录具体步骤、原因及可见证据。
9. 将结果写入 `.ai-auto-test/results/<run-id>/summary.md`，不要写入密码或验证码。
10. 完成后汇总各种结果数量，并列出所有需要人工处理的用例。

开始前先用目标 URL 做 Browser Preflight。输入齐全且 Preflight 成功后直接执行，不要搜索 MCP、扫描项目目录、设计测试框架或生成 Playwright 脚本。
